# MarsView

MarsView is an independent Mars mapping and cartography project for the NASA Space Apps Challenge 2026, as supplied in the brief. The audience is challenge visitors, space enthusiasts, developers, and scientific-data explorers. The landing page introduces the project through Mars imagery, regional context, and links to NASA sources. Its dashboard calls to action point to `/dashboard`, where the group's replacement page will be integrated.

The brief explicitly pins React, Tailwind CSS, Lucide icons, absolute near-black, diffused Martian copper and amber, uppercase spaced typography, a centered 3D globe, two named calls to action, a mission ticker, asymmetric feature cards, telemetry cards, and a minimal scientific footer. These are the visual authority; the reference video itself was not supplied.

Scope: complete local application in this workspace, no publishing requested. English interface copy follows the supplied English titles. The landing page includes an interactive Mars globe and panorama; its dashboard buttons target `/dashboard`, reserved for the group's page. NASA affiliation, live mission status, and a public project repository are not assumed.
